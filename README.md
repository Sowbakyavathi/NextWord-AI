# NextWord-AI 🤖

### Transformer-Based Next-Token Prediction Using Basic Self-Attention

## 📌 About the Project
NextWord-AI is a beginner-friendly deep learning project that predicts the next word in a sentence using a Transformer model with self-attention.

## 🎯 Objective
To understand how Transformers use self-attention to learn relationships between words and predict the next word.

## 🛠️ Technologies Used
- Python
- PyTorch
- Matplotlib
- Seaborn
- Google Colab

## ✨ Features
- Next-word prediction
- Transformer model implementation
- Training loss graph visualization
- Self-attention heatmap visualization

## ⚙️ How It Works
1. Converts words into numerical IDs.
2. Converts word IDs into embeddings.
3. Applies self-attention to learn relationships between words.
4. Trains the model using next-word targets.
5. Predicts the next word based on the input sentence.

## 📊 Visualizations
- **Training Loss Graph:** Shows how the training loss changes over epochs.
- **Self-Attention Heatmap:** Displays attention weights between words.
- **Next-Word Prediction:** Displays the predicted next word.

## 🚀 How to Run
1. Download the notebook from this repository.
2. Open [Google Colab](https://colab.research.google.com/).
3. Upload the `.ipynb` notebook.
4. Run all cells in order.
5. View the prediction and visualization outputs.

## 📚 Learning Outcomes
- Understanding Transformer fundamentals
- Learning basic self-attention
- Building a next-token prediction model
- Visualizing training loss and attention weights

## ⚠️ Limitations
This project uses a small sample dataset for learning purposes. Predictions are limited by the dataset and are not intended for real-world language generation.
